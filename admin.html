    Import CSV/Excel — tâches, événements, décisions

    Colonnes attendues (une ligne = un objet, l'ordre des colonnes n'a pas d'importance) : Type, Libellé, Détail/Description, Date, Heure, Date fin, Responsable, Dossier, Réunion source, Décision liée, Sous-point de, Priorité, Statut, Source (l'en-tête "Origine" est aussi accepté comme synonyme de "Source"). "Type" (tache / evenement / decision / dossier / odj) et "Libellé" sont les seules colonnes obligatoires — laisse les autres vides si non pertinentes pour une ligne, ça n'empêchera jamais l'import du reste. "Dossier" : pour rattacher une tâche/un événement/une décision à un dossier déjà existant sur le site, OU à un dossier créé par une ligne "Type=dossier" plus haut dans le même fichier — dans ce cas, mets bien la ligne "dossier" AVANT les lignes qui le référencent, sinon elle ne sera pas encore reconnue. Pour une ligne "dossier" : "Libellé" = nom du dossier, "Statut" accepte "à faire"/"en cours"/"en pause"/"terminé", "Responsable" fonctionne comme pour une tâche (nom d'un membre existant). "Réunion source" (tâches et décisions) : la date de la réunion (AAAA-MM-JJ ou JJ/MM/AAAA), pour la relier à la réunion correspondante si elle existe déjà — sinon juste un avertissement, jamais bloquant. Pour une ligne "odj" : "Libellé" = le texte complet du point (une vraie phrase, affichée telle quelle sur la page publique) et "Réunion source" est cette fois OBLIGATOIRE (un point d'ODJ doit toujours être rattaché à une réunion existante — sinon la ligne est rejetée). "Sous-point de" (uniquement pour "Type=odj") : le libellé EXACT d'un point principal de la même réunion, déjà existant sur le site ou créé par une ligne "odj" plus haut dans le même fichier — transforme ce point en sous-point affiché indenté sous son parent côté public ; laisser vide pour un point principal. Un seul niveau d'imbrication possible (un sous-point ne peut pas avoir lui-même de sous-point). "Statut" accepte aussi "proposition"/"proposé" (tâche/événement/décision), "à confirmer"/"réalisé"/"annulé" (événement), "en discussion" (décision), "annulée" (tâche). "Source" : texte libre pour tracer l'origine (PV, calendrier académique, programme annuel, compte-rendu externe...). Une ligne dont le libellé (et la date si présente) ressemble à quelque chose déjà présent sur le site déclenche un avertissement "potentiellement déjà existant" dans l'aperçu — jamais une suppression ou un blocage automatique.

    Le fichier n'est jamais enregistré : il est juste lu dans ton navigateur, et rien n'est écrit dans la base tant que tu n'as pas relu l'aperçu et cliqué "Confirmer les ajouts" ci-dessous.

    Import délégués — nom + programme(s)

    Colonnes attendues : Nom, Programmes ("Programmes" = un ou plusieurs codes séparés par des points-virgules, ex: GESM1BA-B1 ou GESM1BA-B1;COMM2M ; laisse vide si pas encore connu). Pour chaque ligne : si le nom correspond à un membre déjà présent sur le site (comparaison insensible à la casse/espaces), ses programmes sont mis à jour SANS toucher à son mot de passe, son statut Admin ou son poste ; sinon un nouveau membre est créé avec un mot de passe généré à partir du nom (affiché dans l'aperçu, à communiquer à la personne).

    Comme pour l'import ci-dessus, rien n'est écrit tant que tu n'as pas relu l'aperçu et cliqué "Confirmer".

    Export CSV — état complet à l'instant présent

    Un seul fichier CSV avec toutes les infos du site, organisées en sections (une section par type : membres, disponibilités, tâches, réunions, événements, décisions, dossiers, sondages). Pensé pour être relu par une IA afin de générer directement un ordre du jour, un procès-verbal ou un bilan — chaque section garde l'historique complet (qui a répondu, qui n'a pas répondu, qui a accepté/refusé une tâche, etc.), pas seulement un résumé.

    Une fois activé, un onglet "📝 Ordre du jour" apparaît sur le site pour les conseillers : ils peuvent y lire les points de la prochaine réunion, laisser un avis/question sur chacun, et suggérer un nouveau point (à valider ici, dans "Suggestions ODJ").

    Une fois activé, un onglet "📋 Tâches" apparaît sur le site (visible uniquement une fois connecté) : il regroupe le tableau de bord — mes tâches, les tâches en retard de l'équipe, la prochaine réunion, les événements à venir.

    Une fois activé, un bouton "🔑 Changer mon mot de passe" apparaît à côté de "Se déconnecter" pour tout membre connecté (toi y compris).

    Force la vue de tout le monde (y compris toi) à s'ouvrir sur cette date au lieu d'aujourd'hui — utile pour pointer une période précise, par exemple la date d'un événement à venir. Tu peux aussi cliquer "Cibler" directement sur un événement dans l'onglet Événements.

    Membres

    Coche "Admin" pour donner l'accès complet à cette page à quelqu'un — il/elle l'utilisera avec son propre mot de passe, pas besoin d'un second mot de passe séparé. Le "Poste" donne aussi un accès partiel à cette page ("sous-admin", sans cocher Admin) : Secrétaire → Réunions/ODJ/Suggestions ODJ/Import, Trésorier → Dossiers/Export, Responsable communication → Tâches/Dossiers. Présidente/Vice-présidente donnent en plus accès à un onglet "Disponibilités" côté public (qui est dispo/pas dispo/n'a pas répondu par événement).

      Cours récurrents

      Se répète chaque semaine sur ce jour — grisé et non cliquable pour tout le monde.

        Événements

          Qui est dispo pour un événement ?

          Tâches (ex : issues d'un PV)

          Mode :

          N'importe quel membre connecté peut cliquer "je m'en occupe" tant qu'il reste de la place ; chacun peut se retirer ensuite.

          La ou les personnes choisies sont fixées sur cette tâche — elles ne peuvent pas se retirer elles-mêmes, seul toi (l'admin) peux la réattribuer.

          Chaque personne cochée voit la tâche proposée et peut Accepter (elle la rejoint) ou Refuser. Ce n'est pas une assignation forcée : si tout le monde refuse, elle redevient une tâche libre pour tous.

          Vue d'ensemble — qui fait quoi, pour quand

            Sondages

            Type de réponse :

            Sondages

              Suggestions de point d'ODJ (par les conseillers)

              Ne s'affiche ici que si l'onglet "Ordre du jour" est activé côté public (Paramètres). "Accepter" crée un vrai point d'ODJ sur la prochaine réunion prévue ; "Rejeter" la retire sans rien créer.

                Dossiers

                  Vue d'un dossier — tout ce qui lui est lié

                  Décisions

                    Trouver une date de réunion

                    1. Donne la plage de dates : les membres voient un bandeau et remplissent leurs dispos sur cette plage. 2. Suis le remplissage et les meilleurs créneaux, qui se recalculent tout seuls. 3. Publie le sondage quand il y a assez de monde. 4. Choisis le créneau gagnant : la réunion et l'événement sont créés.

                    Réunions

                    Une réunion se crée à partir d'un événement déjà présent au calendrier. Les présences sont pré-remplies automatiquement d'après les disponibilités marquées sur ce créneau (seuil de l'événement, 45 min par défaut) — modifiable ensuite librement.

                      Remplir les disponibilités d'un membre

                      Pratique si un membre te communique ses dispos autrement (oral, message) : ça enregistre directement à sa place, comme s'il/elle avait cliqué lui-même/elle-même.

                      Marquer en :

                      ⚡ Marquage rapide (par règle) — pour ce membre

                      Marque d'un coup toutes les cases qui correspondent aux critères ci-dessous, pour le membre choisi ci-dessus (ex: "tous les mardis de 14h à 16h", "tout le mois", "tous les midis").

                      Jour(s) :
                      Marquer en :

                      Règle rapide pour plusieurs membres à la fois

                      Même principe que le "Marquage rapide" côté membre, mais applicable directement à plusieurs personnes en un coup — pratique si tout un groupe t'a communiqué les mêmes dispos (ex: "tous indisponibles le mardi matin, cours").

                      Jour(s) :
                      Marquer en :

                      0 / 0 membres ont indiqué au moins une disponibilité

                      Laisse vide pour compter "au moins une dispo, n'importe quand" (comme ci-dessus). Remplis les deux dates pour voir qui a mis au moins une dispo/indispo précisément dans cette plage.

                      ⚠️ Des réponses existent encore pour des personnes qui ne sont plus dans la liste des membres (ex : suppression faite avant un correctif) — elles ne comptent plus dans les stats ci-dessus, mais tu peux les effacer définitivement :

                        Superposer les cours sur la grille de dispo

                        Choisis une faculté/année/des programmes (ou coche des cours précis), puis "Afficher sur la grille" : les créneaux où ces cours ont lieu sont surlignés en violet sur la grille de dispo ci-dessous — survole une case pour voir le détail (ex: "Bac1 Gestion : Comptabilité", "Bac2 Gestion : ...").

                        Pratique pour exclure une catégorie d'un coup : cherche "monitorat", "Décocher les résultats affichés", puis cherche "TP" et refais pareil — les décochés restent exclus même quand tu changes de recherche.
